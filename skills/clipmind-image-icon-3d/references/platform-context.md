# 3D 图标：独立 Codex 运行映射

## 运行边界

本 Skill 从自媒体工作台的有效定义导出，但交付后完全在操盘手自己的 Codex 中运行。不要连接原平台数据库、API、账号、任务状态或客户素材库。

## 输入映射

| 平台概念 | 独立包中的来源 |
|---|---|
| IP 档案 / 客户上下文 | 当前 `ip-cases/<案例编号>/PROFILE.md` |
| 素材库 / material_lookup | 当前案例的 `materials/`、`MATERIALS.md`、`EVIDENCE-INDEX.md` |
| 已确认策略 / 计划 | 当前案例中用户明确标记“已确认”的文件 |
| 页面展示字段 | 当前对话或 `outputs/` 中对应的短文案、详情文案 |
| 保存 / 写入业务状态 | 禁止执行；只生成候选文件并等待人工确认 |

## 能力缺口

需要联网、图片生成或外部应用时，先检查当前 Codex 是否确实提供对应能力。没有能力就说明缺口并交付可复制的替代产物，不得伪装调用成功。
