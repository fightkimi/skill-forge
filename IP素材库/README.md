# 当前 IP 素材库

默认不需要操盘手导入资料。第一次运行 `progress.py init` 且本目录为空时，项目会把 `fixtures/ip/小月/` 中的 MOCK 合成演练资料复制到这里，供 32 个纯文案 Skill 使用。

自动装载后包含：

- `MATERIALS.md`：材料清单和使用边界。
- `PROFILE.md`：小月合成演练档案。
- `EVIDENCE-INDEX.md`：MOCK 事实、来源和证据强度。
- `原始材料/`：访谈、产品、用户、案例、语料、内容样本、表现数据和阶段目标。

这些运行副本和调试结果默认被 Git 忽略；版本化演练源文件保存在 `fixtures/`。

## 使用真实资料时

如项目所有者以后决定改用真实 IP，可以在初始化前把材料放入 `原始材料/`。只要检测到任何用户材料或档案，项目就不会复制、覆盖或混入小月演练数据。不要把两套 IP 材料放在同一目录。
