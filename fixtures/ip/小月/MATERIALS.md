## 材料之间的关系

### 档案层

PROFILE.md 是“小月目前被确认为怎样的人”的摘要。它适合快速建立上下文，但任何涉及结果、数字、客户反馈或具体经历的内容，都要回到 EVIDENCE-INDEX.md 和对应原始材料。

### 事实层

01 与 02 主要回答“小月是谁、做什么、为什么这样做”；03 与 04 回答“用户怎么说、案例真实发生了什么”；07 回答“本轮合成样本里出现了什么表现信号”。这些材料的证据强度不同，不能混成同一等级。

### 表达层

05 提供小月的表达习惯与禁区，06 提供可以直接做改写前后对比的文本。语言 Skill 应同时读取两者：只读语料会缺少完整任务，只读历史内容则可能把不合格样本误当成风格标准。

### 策略层

08 是阶段任务和产能约束，不是长期战略真理。计划、排期和选题 Skill 必须同时读取它与 07；不能只根据表现高低排内容，也不能只按选题池填满日期。

## 证据强度

- **A｜可稳定使用**：至少两份材料互相印证，且没有已知冲突。
- **B｜可作为候选**：有明确来源，但仍是单方记录或小样本判断。
- **C｜只能带限制引用**：包含同期变化、无法独立归因的数据或单案例结果。
- **D｜缺口/禁止外推**：没有证据、明确冲突、涉及隐私或外部事实，不得补写。

任何内容只要涉及粉丝、咨询、成交、返工下降、客户数量和服务结果，至少要标出证据 ID 与限制。没有证据 ID 时，应写“资料未提供”而不是从常识补齐。

## 已知交叉核对点

1. 小月口述“接触过二十多个项目”，当前能形成过程记录的只有五个 MOCK 案例，不能把二十多个写进对外介绍。
2. CASE-B 的私信变化与产品页、社群活动同期发生，不能归因于内容单项。
3. D02、D09 收藏较高，但用户问题仍偏模板索取，不能把收藏直接当成购买意向。
4. CASE-C 计划失败既有产能误判，也有授权延迟，不能只归咎老板不配合。
5. 小月强调谨慎，但内容表现显示过度铺垫会损伤停留；“谨慎”不等于“慢”。
