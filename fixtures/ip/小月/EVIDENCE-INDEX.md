# 小月演练证据索引

> **MOCK 合成演练数据**：本文件只用于 Skill Forge 调优。“小月”及全部来源、案例、指标均为虚构，不对应真实人物、客户或经营结果，不得用于外部宣传。

## 证据等级

- **A｜强**：至少两份材料互相印证，当前资料没有已知冲突，可作为演练中的稳定上下文。
- **B｜中**：来源明确，但主要来自单方访谈、少量样本或内部记录，应写成候选判断。
- **C｜弱**：包含同期变化、无法独立归因的结果或单案例反馈，只能带限制引用。
- **D｜缺口**：没有材料支持、信息明确冲突、涉及隐私或外部事实，禁止补写。

## 引用规则

1. 关键结论优先附证据 ID；涉及数字、结果和客户反馈时必须附。
2. A 级可以作为本轮稳定上下文，但仍须标注 MOCK。
3. B 级使用“当前材料显示、候选判断、在这些样本中”等限定。
4. C 级必须同时写限制，不得只摘结果。
5. D 级直接留白或提出最少补充问题，不得借互联网或模型记忆补齐。
6. 同一内容如同时引用成功和失败案例，不能为了叙事顺畅删除失败条件。
