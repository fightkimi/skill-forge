# 赵玥玥 IP 演练资料

> **MOCK 合成演练数据**：本目录只用于 Skill Forge 调优，不对应真实个人、客户或经营结果，不得用于外部宣传。

## 使用目的

这套资料模拟一个“从一线操盘经验走向方法化表达”的内容操盘手 IP。它让操盘手打开项目后即可逐项调用文案 Skill，不需要先上传客户资料。

所有人物、品牌、产品、案例、对话、指标和时间线均为虚构。材料故意包含：

- 可以直接引用的强证据。
- 只有单方记录支持的弱证据。
- 前后存在差异、需要人工判断的冲突信息。
- 不应被包装成普遍事实的单个案例。
- 明确禁止承诺的效果和边界。

调优时必须沿用证据索引，不得把 MOCK 案例改写成真实业绩，也不得把赵玥玥的个案信息写进通用 Skill。

## 默认工作模式

1. 从 `scenarios.json` 取得当前 Skill 的固定任务和材料。
2. 按当前 Skill 生成一轮结果。
3. 操盘手只评价结果，不直接改 Schema、角色或工作流。
4. Codex 只把跨案例可复用的文案方法写回 Skill。
5. 使用同一任务和材料复跑，直到操盘手明确确认。
