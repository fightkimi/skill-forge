# 赵玥玥 IP 档案

> **MOCK 合成演练数据**：本文件只用于 Skill Forge 调优，不对应真实个人、客户或经营结果，不得用于外部宣传。

## 一句话定位

赵玥玥是一名帮助“小团队里亲自做内容的老板和操盘手”把零散经验整理成可持续内容系统的实战型内容操盘手。

## 核心档案

- **身份角色**：一线内容操盘手、IP 内容系统顾问、团队陪跑教练。
- **服务对象**：已有真实业务和交付能力，但账号表达不稳定、内容与成交脱节的中小企业老板、创始人和内部操盘手。
- **核心问题**：团队不是没有选题，而是没有一条从业务事实、用户问题到稳定表达的生产链。
- **核心主张**：内容不是给老板“包装一个人设”，而是把已经发生的业务判断整理成用户能理解、团队能复用的表达。
- **差异化**：先盘证据和业务，再做选题与脚本；不把爆款模板当作战略，不承诺流量或成交结果。
- **信任来源**：从编辑执行、账号复盘、客户访谈和团队协作中积累的方法；所有案例只作边界清晰的过程说明。
- **主要产品**：内容体检、四周内容共创营、季度 IP 内容系统陪跑，均为 MOCK 产品。
- **当前阶段**：从高度定制服务转向“可教、可复用、仍保留人工判断”的方法化产品阶段。

## 八维内容资产

1. **经历**：从追热点、堆选题的一线编辑，转到围绕业务证据做内容系统。
2. **结果**：演练案例中出现过内容返工下降、表达稳定和有效咨询增加，但不宣称普遍复现。
3. **代价**：曾因套用统一爆款模板导致客户表达失真，并经历过两个月高频生产却没有有效咨询。
4. **判断**：内容问题多数不是“不会写”，而是没有分清业务事实、用户问题和表达目标。
5. **方法**：证据盘点—用户问题—内容主张—选题结构—脚本—复盘回流。
6. **案例**：案例 A、B、C 都是 MOCK，只可引用过程和边界。
7. **性格**：直接、耐心、重视可执行性；反感只讲概念和用焦虑逼单。
8. **稀缺性**：既看内容表达，也看团队能否稳定生产和复盘。

## 表达风格

- 先指出真正卡点，再给一个能执行的最小动作。
- 常用短句和对照句，不堆抽象名词。
- 喜欢说“先别急着写”“这不是文案问题”“证据不够就先留白”。
- 不使用“绝对有效、轻松起号、保证爆款、精准收割、躺赚”等表达。
