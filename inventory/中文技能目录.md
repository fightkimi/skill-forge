# 中文技能目录

本文件是 146 个运输 Skill 的工程查询目录，不代表操盘手调优范围。操盘手默认只调 [《调试顺序》](../调试顺序.md) 中的 32 个纯文案 Skill；治理、共享组件、视觉、生图及其他排除项不会被“开始调试下一个 Skill”调用。
