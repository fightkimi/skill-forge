# 共享规则，不是可调用 Skill

本文件供各内容 Skill 在需要去除 AI 腔或检查表达自然度时参考；它没有独立 Skill 身份，不能单独调用。

## 原始规则

## AI 味清单（先归因到层，再逐项检查，命中即写进 problem_tags）

去 AI 味不是替换几个词——机械避词只会换出新的 AI 味。先判断这段"AI 味"卡在哪一层，再回到对应修法；改写时永远回到「这个 IP 本人会怎么说」，而不是套通用模板。

### 第一步 先归因：AI 味出在哪一层（决定怎么改，不是只打标签）

1. **IP 层**——不像这个人在说话（语气 / 判断 / 举例不是 ta 的）。修法：回 IP 语言库，按本人的开头、判断、举例、收口重写。
2. **用户关系层**——没有对象感，不像在对一个具体的人说。修法：明确在对谁说、ta 此刻在担心什么。
3. **判断来源层**——判断像万能总结，换个专家也能讲（把 IP 名字遮住就认不出是谁）。修法：换成只有这个 IP 的经历 / 证据撑得住的那一个判断。
4. **场景层**——只有抽象概括，没有能想象的现场。修法：补一个具体的人、动作、原话、后果。
5. **承接层**——结尾空泛，用户不知道下一步做什么。修法：给一个低门槛的具体动作。

> **硬规则：没有 IP 语言库（语气 DNA）时，不允许直接出终稿——只能出结构稿 + 补料问题。** 任何禁词式去味都替代不了"先学这个人怎么说话"。

### 第二步 逐项：8 类 AI 味标签（命中写进 problem_tags）

1. **空泛大词**（`套话重`）赋能 / 抓手 / 闭环 / 生态 / 链路 / 全方位 / 一站式——无信息量的宏大词堆砌。改：换成具体的人、事、动作。
2. **三段式模板**（`三段式模板`）总-分-总、"第一…第二…第三…"、工整到像填空的排比结构。改：打破对称，按真实重点先后说。
3. **讲义腔连接词**（`语气不够自然`）首先 / 其次 / 最后 / 综上所述 / 值得注意的是 / 总而言之。改：用口语的"然后""但""你看"或直接去掉。
4. **AI 高频动词**（`假专业`）打造 / 助力 / 深入 / 精准 / 有效提升 / 持续优化 / 全面布局。改：换成动作本身（做、改、加、删）。
5. **正确的废话**（`像 AI 总结`）"内容要优质""坚持就会成功""用户需求很重要"——无人反对、放之四海皆准的空话。改：给一个有立场、可能被反驳的具体判断。
6. **强行升华**（`过度总结`）结尾硬拔高意义、喊口号、上价值，与正文脱节。改：去掉升华，停在具体的一句。
7. **缺真实细节**（`缺真实细节`）没有具体场景 / 数字 / 案例 / 本人原话，全是抽象概括。改：补一个真实细节；无真实素材时标「(待人工补充)」，不得编造。
8. **动作堆砌**（`动作堆砌`）为显得"具体"而堆过多动作（"我先拦一下 / 球过来那一秒 / 第一第二第三第四"）——读起来像分镜表 / 公式，像 AI 知道规则后机械执行，不像人和人在对话。改：只留必要的动作，回到自然口语，把"按规则填空"的味道去掉。

> 输出去味后的成品即可，**不要把上面的"归因 / 标签"过程暴露给用户**（只交付干净的优化版内容）。
