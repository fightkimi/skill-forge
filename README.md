# ClipMind Skill Forge

给 IP 操盘手使用的本地 Skill 调试项目。把同一个 IP 的材料放进指定文件夹后，Codex 会按 ClipMind 真实业务顺序，一次只带你调一个 Skill。

你不需要安装 146 个 Skill，不需要启动 ClipMind，也不需要懂 Prompt、代码或 Git。

## 只做三件事

1. 把这个项目导入 Codex。
2. 把当前 IP 的全部原始材料放进 `IP素材库/原始材料/`。
3. 新建一个 Codex 对话，发送：

   > 请阅读《开始调试.md》，帮我完成 IP 建档并开始第一个 Skill。

从第二个 Skill 开始，每次新建一个对话，只需要发送：

> 开始调试下一个 Skill

每轮结果出来后只选一种回复：

- `OK，完成这个 Skill`
- `不OK：这里写你的修改意见`

Codex 会判断反馈是当前 IP 个案，还是可沉淀进通用 Skill 的方法；只修改反馈涉及的允许板块，并用同一份材料重新生成。你确认 OK 后，它会交付最终校正后的 Skill，再进入下一个。

## 项目覆盖范围

- 88 个内容 Skill：同材料循环调优。
- 22 个生图 Skill：同主题看图循环调优。
- 9 个共享质量组件：至少跨 3 个宿主任务复测后才允许收口。
- 27 个治理 Skill：只读质量验收；如发现问题，生成工程变更建议单，不由操盘手直接改。

合计 146 个。完整顺序见 [调试顺序.md](调试顺序.md)，不可修改范围见 [Skill不可修改边界.md](Skill不可修改边界.md)。

## 安全说明

- IP 原始材料、档案、调试记录和最终回收包默认不会进入 Git。
- `references/original.md` 始终是只读初始基线。
- 本项目不连接、不覆盖 ClipMind 线上 Prompt，也不自动发布、投放、写库或改变业务状态。
- 最终 `SKILL.md` 是供 Codex 调试和工程回收的运输包；真正上线仍需开发按 `source-map.md` 定位真实源文件、真模型复测并走 PR。
