# ClipMind Skill Forge

给 IP 操盘手使用的本地纯文案 Skill 调试项目。项目已经内置一套明确标注为 MOCK 的“小月”合成 IP 材料，Codex 会按真实业务依赖一次调用一个文案 Skill，操盘手不需要先导入资料。

第一次使用可以直接打开 [《操盘手操作指引》](操盘手操作指引.html)。

## 只做三件事

1. 用 Codex 打开这个项目。
2. 新建对话，发送：

   > 请阅读《开始调试.md》，使用小月演练资料开始第一个文案 Skill。

3. 查看生成结果并二选一：
   - `OK，完成这个 Skill`
   - `不OK：这里写你的修改意见`

Codex 不会机械地取列表下一项：它会先检查上游 Skill 是否已完成并获得操盘手确认，再读取下游声明需要承接的最终输出。每次首轮、反馈、复跑和确认时，回复开头都会显示“当前调试”卡，写清第几项、中文名、所在环节、为什么现在调、承接哪些产物以及本轮产出。

收到“不OK”后，它只会在允许边界内修改当前 Skill，并用同一任务、材料和上游输出快照重新生成。操盘手确认 OK 后才会交付最终校正包。

从第二个 Skill 起，新建对话并发送：

> 开始调试下一个 Skill

## 操盘手范围

- 默认调优 32 个纯文案 Skill。
- 覆盖 IP 建档与定位、用户洞察、策略与内容计划、平台策略、脚本与平台文案。
- 7 个爆款拆解、评论、CTA、朋友圈和私域文案 Skill 默认关闭，只由项目所有者按需启用。
- 治理、共享组件、视觉、生图、资料入库、发布、投流、监控和数据能力不进入操盘手队列。

完整顺序见 [《调试顺序》](调试顺序.md)，冻结边界见 [《Skill 不可修改边界》](Skill不可修改边界.md)。

## 内置资料说明

`fixtures/ip/小月/` 中的经历、产品、客户、案例和数据全部是合成演练内容，不对应真实人物，也不得用于外部宣传。第一次初始化且 `IP素材库/` 为空时，项目会自动复制这套资料；如果素材库已有用户资料，项目绝不覆盖或混入演练数据。

当前资料包约 4.8 万字符，包含两轮人物深访、12 组用户访谈、24 条评论/私信、5 个正反案例、12 份历史内容样本、24 条合成表现数据和 36 个候选选题，可连续支持建档、策略、计划、洞察与内容生产 Skill。

## 安全说明

- `references/original.md` 由 SHA-256 基线锁保护，不能和候选 Skill 一起被替换。
- Skill 的身份、角色、触发、上下游、输入输出、工具、权限、人工边界和关键结构不能由操盘手修改。
- IP 材料、调试记录和最终回收包默认不会进入 Git。
- 本项目不连接或覆盖 ClipMind 线上 Prompt，也不自动发布、投流、写库或改变业务状态。
- 最终 `SKILL.md` 只是工程回收包；上线仍需开发按 `source-map.md` 定位真实源文件、使用生产模型复测并走 PR。

完整 146 个运输 Skill 仍保留在仓库中供工程追溯，但不会全部展示给操盘手。
